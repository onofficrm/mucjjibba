## 1. 한 줄 요약

묵찌빠는 바카라처럼 “뱅커만 5%”가 아니라, **대칭 PvP 팟(예치합)** 기준의 하우스 엣지를 씁니다.

| 구간 | 모델 | 요율 | 설명 |
|------|------|------|------|
| 기본 테이블 | `pot_rake` | **팟의 5%** | 예치×2 = 팟 → 수수료 차감 후 승자에게 지급 |
| 고액(플래티넘·VIP) | `winner_profit_tax` | **순이익의 5%** | 승자 이익(상대 예치분)에만 과세 → 체감 부담↓ |
| 특수(공격 승리) | `attack_premium` | **팟의 +1%** | 공격권으로 승점을 딴 뒤 승리하면 추가 수수료 |

연습(무료) 테이블은 수수료 **0**.

---

## 2. 용어

| 용어 | 의미 |
|------|------|
| `entry` | 1인 참가 예치 포인트 |
| `pot` | `entry × 2` (양쪽 예치 합) |
| `profit` | 승리 시 순이익 후보 = `entry` (상대분) |
| `houseFee` | 하우스가 가져가는 총액 |
| `winnerPayout` | 승자에게 지갑으로 지급되는 금액(예치 반환 포함 개념의 이미 예치된 경우 이 금액만 크레딧) |
| `loser` | 예치금 소멸(추가 차감 없음, 이미 예치된 경우) |

현재 데모 지갑 흐름:

1. 매칭 성사 시 `entry` 예치(차감)
2. 승리 시 `winnerPayout` 크레딧
3. 패배 시 추가 변동 없음(예치분 소멸)

## 3. 모델 상세

### 3.1 기본 — 팟 레이크 `pot_rake` (5%)

적용 테이블: `practice`(0%), `bronze`, `silver`, `gold` (+ 친구방 기본)

```
pot        = entry × 2
houseFee   = round(pot × 0.05)
winnerPay  = pot − houseFee
```

예시 (브론즈 entry=1,000)

| 항목 | 금액 |
|------|------|
| 팟 | 2,000 |
| 수수료(5%) | 100 |
| 승자 지급 | 1,900 |

### 3.2 고액 — 승자 순이익세 `winner_profit_tax` (5%)

적용 테이블: `platinum`, `vip`

```
pot        = entry × 2
profit     = entry
houseFee   = round(profit × 0.05)
winnerPay  = pot − houseFee
```

예시 (플래티넘 entry=50,000)

| 항목 | 금액 |
|------|------|
| 팟 | 100,000 |
| 순이익 | 50,000 |
| 수수료(이익의 5%) | 2,500 |
| 승자 지급 | 97,500 |

> 같은 5%라도 **팟 5%보다 하우스 몫이 절반**이어서 고액 테이블 VIP 체감이 좋아집니다.

### 3.3 특수 — 공격권 프리미엄 `attack_premium` (+1% of pot)

조건 (모두 충족):

1. 유료 매치
2. 내가 승리
3. 로그상 `POINT_ME` 이면서 `attackerBefore === 'ME'` 인 라운드가 **1회 이상**  
   (= 공격권으로 승점을 딴 적이 있음)

효과:

```
extraFee   = round(pot × 0.01)
houseFee  += extraFee
winnerPay -= extraFee
```

예시 (브론즈 + 공격 승점 후 승리)

| 항목 | 금액 |
|------|------|
| 기본 수수료 | 100 |
| 공격 프리미엄 | 20 |
| 총 수수료 | 120 |
| 승자 지급 | 1,880 |

비활성 조건: 연습 모드, 패배, 공격 승점 없이 승리(수비만으로 종료 등).

## 4. 테이블별 기본 정산표 (프리미엄 미적용·잭팟 미적용)

| 테이블 ID | entry | 모델 | 기본 수수료 | 기본 승자 지급 |
|-----------|------:|------|------------:|---------------:|
| practice | 0 | — | 0 | 0 |
| bronze | 1,000 | pot_rake 5% | 100 | 1,900 |
| silver | 5,000 | pot_rake 5% | 500 | 9,500 |
| gold | 10,000 | pot_rake 5% | 1,000 | 19,000 |
| platinum | 50,000 | profit_tax 5% | 2,500 | 97,500 |
| vip | 100,000 | profit_tax 5% | 5,000 | 195,000 |

> `types/match.ts` 의 `fee` / `winnerPoint` 는 위 표와 **동일하게** `houseFee` 헬퍼로 생성합니다.

---

## 5. 잭팟과의 관계

잭팟 배수는 **수수료 차감 후** `winnerPayout` 에만 곱합니다.

```
finalCredit = floor(winnerPayout × jackpotMultiplier)
```

하우스는 기본·프리미엄 수수료만 가져가고, 잭팟 보너스는 마케팅/이벤트 비용으로 봅니다.
